<h3 id="✨-텍스트를-꾸며주는-태그들">✨ 텍스트를 꾸며주는 태그들</h3>
<p><code>&lt;h1-6&gt;</code> : heading 제목 표시.
<code>&lt;p&gt;</code> : paragraph 단락 만들기.
<code>&lt;span&gt;</code> : 영역묶기.
<code>&lt;br&gt;</code> : breake line 줄 바꾸기.
<code>&lt;hr&gt;</code> : horizontal line 수평 줄 넣기.</p>
<p><code>&lt;blockquote&gt;</code> : 인용문 넣기 (블럭 요소) &gt; 들여쓰기 됨.
<code>&lt;q&gt;</code> : 인용문 넣기 (인라인 요소) &gt; 쌍따옴표 표시.
<img alt="" src="https://images.velog.io/images/jiwon_kim/post/4e6d98b2-4185-4a06-a38c-95618d3fdb27/%ED%85%8D%EC%8A%A4%ED%8A%B8%EC%84%9C%EC%8B%9D1.PNG" /></p>
<p><code>&lt;em&gt;, &lt;i&gt;</code> : 이탤릭체 표시.
<code>&lt;pre&gt;</code> : 입력문자 그대로 화면에 표시. 수학기호나 공식을 작성할 때 브라우저가 기호를 태그로 인식해서 잘못 출력될 경우 사용.</p>
<p><code>&lt;strong&gt;, &lt;b&gt;</code> : 문자 강조표시.
<code>&lt;del&gt;, &lt;s&gt;</code> : 취소선.
<img alt="" src="https://images.velog.io/images/jiwon_kim/post/71c9a705-7e4e-4bef-90e5-fca7645578be/%ED%85%8D%EC%8A%A4%ED%8A%B8%EC%84%9C%EC%8B%9D2.PNG" /></p>
<hr />

<h4 id="🤔-strong과-b-del과-s는-같은-효과를-내는데-무엇이-다를까">🤔 <code>&lt;strong&gt;</code>과 <code>&lt;b&gt;</code>, <code>&lt;del&gt;</code>과 <code>&lt;s&gt;</code>는 같은 효과를 내는데 무엇이 다를까?</h4>
<p>  <u>텍스트 리더기를 통해 들을 때</u> <code>&lt;strong&gt;</code>은 태그 안의 문자를 강조해서 읽어주지만 <code>&lt;b&gt;</code>는 강조해서 읽어주지 않는다.
  마찬가지로, <code>&lt;del&gt;</code>은 태그 안의 문자를 읽지 않지만 <small>(취소선이기 때문에)</small> <code>&lt;s&gt;</code> 태그는 다른 문자들과 똑같이 읽어준다. </p>
<p>  시각장애인이나 텍스트 리더기를 통해 들을 경우를 고려한다면 <code>&lt;strong&gt;</code> 태그나 <code>&lt;del&gt;</code> 태그를 이용하는 것이 좋다.</p>
<hr />



<p><code>&lt;mark&gt;</code>: 형광펜 효과 내기.
<code>&lt;crite&gt;</code> : 참고 내용 표시.
<code>&lt;big&gt;</code> : 브라우저의 기본 폰트(16px)를 기준으로 폰트를 조금 크게 표시.
<code>&lt;small&gt;</code> : 브라우저의 기본 폰트(16px)를 기준으로 폰트를 조금 작게 표시.
<code>&lt;sub&gt;</code> : 아래첨자
<code>&lt;sup&gt;</code> : 윗첨자
<code>&lt;u&gt;</code> : 밑 줄
